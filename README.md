# E-Commerce Website

An e-commerce website built with **React** and **Tailwind CSS**, fetching data from an API for product listings. The application is deployed on **Vercel** for seamless access.

## Features

- **Responsive Design**: Optimized for all devices using Tailwind CSS.
- **API Integration**: Fetches live data for product listings.
- **Product Display**: Displays a list of products with images, prices, and details.
- **Interactive UI**: Smooth and dynamic user experience using React components.
- **Deployed on Vercel**: Fast, reliable, and scalable hosting.

## Technologies Used

- **Frontend**: React, Tailwind CSS
- **API**: Fetching product data via REST API
- **Deployment**: Vercel
